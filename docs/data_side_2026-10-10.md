- ทั้งคู่ใช้ Validation (2022-09 → 2024-05) และ Test (2024-05 → 2025-12, 2,572 แท่ง) **แถวเดียวกันเป๊ะ**
  — runner ใหม่ `--train_start` ตัดเฉพาะแถวก่อนวันที่ แล้วคำนวณ `--train_pct` / `--oos_start` ใหม่ให้ตรงแถวเดิม (ตรวจแล้ว: identical val/test rows = True)
- คำสั่ง:
  ```bash
  .venv/Scripts/python.exe tools/analysis/obs_ablation.py --arms D --seeds 0,1,2 --train_start 2019-01-01 --prefix reg2019 --tag regime_2019
  .venv/Scripts/python.exe tools/analysis/obs_ablation.py --arms D --seeds 0,1,2 --prefix full --tag regime_full
  ```
- เกณฑ์อ่านผล: 2019 ดีกว่า full เมื่อ PF เฉลี่ยข้าม seed สูงกว่า **และ** pooled PF สูงกว่า **และ** ไม่มี seed ไหนแย่กว่า full seed เดียวกันมาก
  edge จริงยังต้องผ่าน "ขอบล่าง PF 95% CI > 1" — ด้วย ~150 เทรด/seed ข้อนี้แทบเป็นไปไม่ได้ (§4) จึงเป็นการทดสอบทิศทาง ไม่ใช่การยืนยัน edge

### 70/15/15 บน dataset ใหม่ได้แค่ไหน

Test = 2,572 แท่ง (2024-05 → 2025-12) → arm D ~149 เทรด, arm A ~213 เทรด → **ไม่ถึง 250** และตรวจได้แค่ PF ≥ ~2.0
การขยาย Test ใน split เดียว (เช่น 60/20/20) ได้เพิ่มแค่ ~30% และไปกินข้อมูลเทรน — ไม่คุ้ม

### ข้อเสนอ: walk-forward รวม OOS (rolling 7 folds × 2 symbols)

train 6,000 แท่ง (~3.8 ปี) · validation 750 (~6 เดือน, ใช้เลือก best checkpoint) · test 1,500 (~1 ปี) · เลื่อนทีละ 1,500

| fold | train | validation | test |
|---:|---|---|---|
| 1 | 2014-12 → 2018-11 | 2018-11 → 2019-05 | 2019-05 → 2020-04 |
| 2 | 2015-12 → 2019-10 | 2019-10 → 2020-04 | 2020-04 → 2021-04 |
| 3 | 2016-12 → 2020-10 | 2020-10 → 2021-04 | 2021-04 → 2022-03 |
| 4 | 2017-11 → 2021-09 | 2021-09 → 2022-03 | 2022-03 → 2023-03 |
| 5 | 2018-11 → 2022-09 | 2022-09 → 2023-03 | 2023-03 → 2024-02 |
| 6 | 2019-10 → 2023-08 | 2023-08 → 2024-02 | 2024-02 → 2025-02 |
| 7 | 2020-10 → 2024-08 | 2024-08 → 2025-02 | 2025-02 → 2025-12 |

- Test รวม 10,393 แท่ง (2019-05 → 2025-12) ทุกแท่ง OOS จริงสำหรับโมเดลของ fold นั้น (checkpoint เลือกบน validation ของ fold เอง)
- arm D: ~600 เทรด/symbol → ตรวจได้ PF ≥ 1.43 · รวม xauusd ~1,200 เทรด → **PF ≥ 1.29**
- เกณฑ์ผ่าน: ขอบล่าง PF 95% CI ของเทรดรวมทุก fold > 1.0 **และ** PF > 1 ใน ≥ 5 จาก 7 fold ต่อ symbol (กันผลที่มาจาก fold เดียว)
- ต้นทุน: ~16 นาที/fold ที่ 200k steps → 7 folds × 2 symbols ≈ 4 ชม. (1 seed ต่อ fold — 7 การเทรนอิสระเฉลี่ย variance แทน 3 seed)
- ความยาว train แบบ rolling 6,000 vs anchored (ทั้งหมดก่อนหน้า) ให้ผลข้อ 3 เป็นตัวตัดสิน
- `rl_walkforward.py` ที่มีอยู่ใช้แทนไม่ได้: ประเมิน test ด้วย TradingEnv (ไม่มี SL/TP/ต้นทุน) และไม่เก็บรายการเทรด
  → ต้องมี runner ใหม่ที่ต่อ fold ด้วย `rl_train.py` + `backtest_live.py` (แบบเดียวกับ `obs_ablation.py`) แล้วรวม `*_live_bt_trades.csv` ทุก fold ทำ bootstrap
