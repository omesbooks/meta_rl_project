ชั้น INPUT · N BARS × M FEATURES

ตาราง 1 จุดต่อ 1 input: แถว = แท่งใน window (บนสุด = เก่าสุด), คอลัมน์ = feature บวกอีก 3 จุดคือ position / unrealized pnl / bars in position เมนู inputs เลือกวิธีลงสี:

  • attribution (ค่าเริ่มต้น) สีตามว่า input นั้นดันการตัดสินใจ "ของแท่งนี้" ไปทางไหน (ส้ม +, ฟ้า −) คำนวณจาก gradient × input ของ action ที่เลือก
  • usage (decision test) สีม่วงตามว่าถ้าสลับค่า feature นั้นแล้วการตัดสินใจเปลี่ยนกี่ % เป็นผลทดสอบคงที่ต่อ eval ไม่เปลี่ยนตามแท่ง เทา = ไม่เคยเปลี่ยนการตัดสินใจเลย
  • activation ค่า input ที่ normalize แล้ว ตรงๆ

Tower ACTOR และ CRITIC

แต่ละฝั่งคือ network คนละตัวที่มีขนาดชั้นเท่ากัน ป้าย L1 · 128 บอกลำดับและจำนวน neuron จริง จุด = neuron สีตาม activation ณ แท่งนั้น (ส้ม +, ฟ้า −, สว่าง = แรง) เมนู layers เลือกรูปทรง: sorted (ค่าเริ่มต้น: layer สุดท้ายของ actor แบ่งกลุ่มตาม action ที่ neuron นั้นส่งน้ำหนักไปมากที่สุด มีแถบสีและป้ายกำกับ ชั้นอื่นเรียงจากทำงานมากไปน้อย), grid, column, disc ตำแหน่งจุดในสามแบบหลังไม่มีความหมาย

เส้นเชื่อมคือ ตัวอย่าง เท่านั้น: วาดเฉพาะเส้นที่แรงที่สุด 4 / 8 / 16 เส้นต่อ neuron (เมนู synapses) เพราะของจริงมีหลายแสนเส้น สีส้ม = สัญญาณบวก ฟ้า = ลบ ความเข้ม = น้ำหนัก × ค่าต้นทาง ณ แท่งนั้น

ฝั่งขวา: OUTPUT และ V(s)

ป้าย HOLD / BUY / SELL / CLOSE พร้อม % คือความน่าจะเป็นที่ policy ให้แต่ละ action ณ แท่งนั้น action ที่สูงสุดมีกรอบล้อม (ใน eval replay คือ action ที่ทำจริง) ป้าย V(s) คือค่าเดียวกับ CRITIC V(s) ในแผงสถิติ

แผง TOP DRIVERS (ซ้าย, เฉพาะ look analysis)

7 input ที่ดันการตัดสินใจของแท่งนี้แรงที่สุด แต่ละแถวมี sparkline ของ feature นั้นตลอด window (จุด = lag ที่ input ตัวนั้นอ้างถึง เส้นประ = ศูนย์), แถบความแรง และตัวเลข + / − เมื่อเลือก inputs = usage แผงจะเปลี่ยนเป็น USED BY THE POLICY: feature ที่ใช้มากสุด และสรุปว่ามีกี่ตัวที่ไม่เคยเปลี่ยนการตัดสินใจเลย

กราฟแท่งเทียน (ล่าง)

แท่งเทียนจริงของช่วง replay เส้นเหลือง = equity สามเหลี่ยมขึ้น/ลง = เปิด long / short จุดกะพริบ = ไม้ปิด (ทอง = กำไร, แดง = ขาดทุน) ใน Cinematic มีอนุภาคแตกกระจายตอนเปิด/ปิดไม้ด้วย

แถบ timeline (ล่างซ้าย)

EVAL k / n · STEP s บอกว่ากำลังเล่น eval ครั้งไหน slider เลือก eval ย้อนหลังได้ sparkline เล็ก = eval reward ของทุก eval (จุดทอง = ที่เลือก) ปุ่ม ● LIVE = ตามอัตโนมัติไป eval ล่าสุด บรรทัดเล็กบอก reward / best / จำนวนไม้

มุมมอง "Training (live)" ระหว่างเทรน

เมนู source สลับได้ระหว่าง Eval replay (policy แบบ greedy บนชุด Validation) กับ Training (live) = rollout ล่าสุดบนชุด Train ที่ policy ยังสุ่มลองอยู่ มุมมองนี้เพิ่ม: จุดบนกราฟตรงแท่งที่ action ที่สุ่มได้ต่างจาก greedy, แถบ advantage ใต้กราฟ, และแผง REWARD / ADVANTAGE / SAMPLED · GREEDY แทนสถิติเทรด หัวกราฟบอก ROLLOUT #k · STEP s (k คือลำดับภาพที่บันทึก ไม่ใช่จำนวนรอบ PPO จริง) rollout ใหม่จะรอให้ replay ปัจจุบันเล่นจบก่อน

การ์ด 6 ใบ

  1. LEARNING CURVE — eval reward ต่อ eval ดูแนวโน้มว่ายังขึ้นอยู่หรือแบนแล้ว
  2. ACTION MIX — สัดส่วนแท่งที่เป็น HOLD/BUY/SELL/CLOSE ในแต่ละ eval ถ้ากลายเป็นสีเดียวแปลว่า policy ล้มไปทางใดทางหนึ่ง
  3. EQUITY ON THE SLICE — เส้น equity ของ "ทุก" eval ซ้อนกัน สีทอง = ล่าสุด เห็นได้ว่าเก่งขึ้นหรือแค่แกว่ง
  4. REPLAY — กราฟแท่งเทียนพร้อมเทรดของ eval ที่เลือก
  5. NEURON ACTIVITY — heatmap neuron × แท่ง (ส้ม +, ฟ้า −) ของแต่ละ layer
  6. LAST TRADES — ตารางไม้ล่าสุดของ eval ที่เลือก

TRAIN vs VALIDATION (หลังทุก eval)

เดิน policy แบบ greedy บน 2 ช่วงที่ยาวเท่ากันและคงที่: ท้ายชุด Train (in-sample) กับชุด Validation (ไม่เคยเห็น) เทียบ return %, PF, win rate, จำนวนไม้, reward ต่อแท่ง ชิปสรุปจาก 4 eval ล่าสุด: GAP WIDENING — OVERFIT? (Train ขึ้น Validation ลง) · GENERALISING (Validation ขึ้น) · VALIDATION PEAKED AT EVAL k (ดีสุดผ่านไปแล้ว ≥ 3 eval) · MEMORISING (ห่างกัน ≥ 5 pp และ Validation ≤ 0) · NO CLEAR TREND

DECISION STABILITY

แท่ง Validation ชุดเดิมในทุก eval: heatmap แถว = eval, คอลัมน์ = แท่ง, สี = action ที่เลือก, ความสว่าง = ความน่าจะเป็น KPI: CHANGED MIND (% การตัดสินใจที่ต่างจาก eval ก่อน), SETTLED SINCE (eval ที่หลังจากนั้นเปลี่ยนไม่เกิน 10% ตลอด), CONFIDENCE, ENTROPY, IN A POSITION ด้านล่างมี slider เลือก eval แล้วดูราคาที่ระบายสีด้วย P(buy) / P(sell) ของ eval นั้น
