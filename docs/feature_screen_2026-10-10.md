# Feature screen — ทุก feature ของ dataset H4 (2026-10-10)

> คำถาม: มี feature ไหน (เดี่ยวหรือรวมกันแบบเส้นตรง) พยากรณ์ **ทิศทาง** ราคาข้างหน้าได้อย่างคงที่ข้ามช่วงเวลาบ้าง
> ต่อจาก 3.1b (`docs/data_side_2026-10-10.md` §5) — div/nearness ไม่ช่วยเพราะตัวสัญญาณเองไม่มีอำนาจพยากรณ์ จึงคัดกรองทั้งชุด
> เครื่องมือ: `tools/analysis/feature_screen.py` · ผลเต็ม: `docs/feature_screen_usdjpy_h4_2025_base.{md,csv}`, `docs/feature_screen_xauusd_h4_2025_v2.{md,csv}`

## สรุป

1. **USDJPY: ไม่มี feature ไหนพยากรณ์ทิศทางได้อย่างคงที่เลย** — 0 จาก 168 ตัว (ที่ stationary) ทุก horizon
   จำนวนที่ |z| ≥ 2 เท่ากับที่เกิดเองโดยบังเอิญ · ridge รวมทุก feature ได้ IC บน Validation/Test = 0.00
2. **XAUUSD: ผ่านเกณฑ์ 3 กลุ่ม แต่ไม่มีกลุ่มไหนเทรดได้จริง** — ADX (IC ~0.01–0.02 และลดลงเรื่อยๆ) ·
   ช่วงเวลาของวัน (เป็น artifact ของ rollover ตอนเที่ยงคืน) · candle_inside (IC ~0.02–0.03)
3. **สิ่งที่ feature พยากรณ์ได้จริงคือความผันผวน ไม่ใช่ทิศทาง** — ATR มี IC กับ |return| +0.26–0.32 (USDJPY), +0.14–0.18 (XAUUSD) คงที่ Train→Validation
4. ผลต่อทิศทางโปรเจค: การจูน PPO / walk-forward / เพิ่ม TA feature แบบเดิม **ไม่น่าจะสร้าง edge ได้** เพราะข้อมูลขาเข้าไม่มีสัญญาณทิศทางให้เรียน

## วิธีวัด (เวอร์ชันที่ถูกต้อง)

- split เดียวกับการทดลอง RL: 70/15/15 ตามเวลา · horizon 1, 5, 20 แท่ง · return = log(close[t+h]/close[t])
- **IC** = Spearman ของ feature กับ return ข้างหน้า คำนวณทั้งช่วง (Train 12,000 แท่ง / Validation / Test ~2,570 แท่ง)
- **z** = IC ของ Train / SE จาก moving-block bootstrap (บล็อก 250 แท่ง 200 รอบ) — จัดการ return ที่ซ้อนกันและ feature ที่ autocorrelate
- **drift** = median |z-score| บน Validation/Test ด้วย mean/std ของ Train · ≥ 2 = non-stationary → ตัดออกจากการตัดสิน
  (USDJPY 14 ตัว: ema_20/50/100/200, ema_long, d1_ema_fast/slow, ex_tema/dema/ama, ex_env_upper/lower, ex_obv, ex_pvt — Test ห่างจาก Train 5–11 SD)
- **stable** = stationary และ |z| ≥ 3 และ IC บน Validation และ Test ไปทางเดียวกับ Train
- **ตรวจกับราคาสุ่ม (null):** สลับลำดับแท่ง USDJPY จริงแบบสุ่ม 20 ชุด (ไม่มีอะไรให้ทำนาย) คำนวณ feature แบบเดียวกัน
  z บน null: mean −0.03, SD 1.08 · |z| ≥ 2 = 6.9% (ทฤษฎี 4.6%) · |z| ≥ 3 = 3.1% (ทฤษฎี 0.3%) → หางหนากว่าทฤษฎีเล็กน้อย
  เมื่อรวมเงื่อนไข Validation + Test แล้ว คาดว่าจะมี feature "stable" โดยบังเอิญราว 1 ตัว

## กับดักที่เจอระหว่างทาง (สำคัญ)

เวอร์ชันแรกคำนวณ IC **ภายในบล็อก 250 แท่ง** แล้วเฉลี่ย → ได้ feature "คงที่" 40 ตัวที่ h=5 (ema_20 t −15, close_zscore t −4.4 ฯลฯ)
ทดสอบเดียวกันบนราคาสุ่มได้ค่าเท่ากันเกือบทุกตระกูล:

| ตระกูล | null block t | ของจริง block t | null IC Val | ของจริง IC Val |
|---|---:|---:|---:|---:|
| ema_20 (ระดับราคา) | −14.2 ± 1.7 | −15.0 | −0.065 | −0.053 |
| ema_200 (ระดับราคา) | −8.2 ± 1.0 | −6.9 | −0.070 | −0.048 |
| dist_ema200 | −9.7 ± 0.9 | −10.4 | −0.003 | −0.033 |
| rsi_36 | −6.3 ± 1.0 | −7.1 | +0.006 | −0.039 |
| close_zscore | −3.8 ± 1.0 | −4.4 | +0.008 | −0.049 |
| rsi_14 | −4.0 ± 1.1 | −3.5 | +0.006 | −0.046 |

สาเหตุ: feature ที่ต่อเนื่องสูง (persistent) ถ้า rank ในหน้าต่างสั้น IC จะติดลบเองเสมอ (bias แบบ unit-root / Stambaugh)
และติดลบ**ทุก**หน้าต่าง จึงหลอกเกณฑ์ "ทิศทางเดียวกันทุกช่วง" ได้ · ระดับราคาโดนหนักสุดแม้วัดทั้งช่วง → ต้องตัดด้วย drift
บทเรียน: **ห้ามวัด IC ในหน้าต่างสั้นกับ feature ที่ persistent** และต้องเทียบกับ null ทุกครั้งที่เจอผลที่ดูดีเกินจริง

13 ตัวที่ h=1 = 3 กลุ่ม:
- **ADX 22–36** (8 ตัว = สัญญาณเดียว): IC +0.024 → +0.015 → +0.008 (Train/Val/Test) ลดลงเรื่อยๆ · แบ่ง ADX เป็น 3 ระดับแล้วไม่มีรูปแบบคงที่ → ใช้ไม่ได้
- **ช่วงเวลาของวัน** (hour, session_*): แท่งแรกของวัน (00:00–04:00 เวลาเซิร์ฟเวอร์) ได้ return เฉลี่ย +0.038 / +0.040 / +0.047% (t 8.0 / 4.1 / 3.4)
  ตรวจด้วย M1: เกิดในนาทีแรกหลังเที่ยงคืนถึง +0.019% และถึง 00:30 รวม +0.027% (~70%) ตรงกับช่วงที่ช่วงราคา M1 กว้างกว่าปกติ 2.3 เท่า (spread ถ่างตอน rollover) และการถือ long ข้าม rollover ยังโดน swap
  ส่วนที่เหลือ 00:30–03:59 ได้ +0.011% (2022–25: t 1.4) ต่ำกว่าต้นทุนไป-กลับ ~0.03% → **artifact ของข้อมูล rollover ไม่ใช่ edge**
- **candle_inside**: IC +0.029 / +0.026 / +0.021 — เล็กเกินจะชนะต้นทุนบน H4

⚠ ความเสี่ยงสำหรับการเทรน RL บน XAUUSD: agent อาจเรียน "ซื้อก่อนเที่ยงคืน" จาก artifact นี้ได้ และ backtest ด้วย spread คงที่จะดูดี แต่รันจริงไม่ได้
ก่อนเทรน XAUUSD ควรห้ามเข้าออเดอร์ช่วง 23:55–00:30 เวลาเซิร์ฟเวอร์ หรือจำลอง spread ช่วง rollover ให้กว้างตามจริง

## ทางเลือกต่อจากนี้

1. **แหล่งข้อมูลใหม่ที่ไม่ใช่ TA จากราคาเดียวกัน** — USDJPY ขับเคลื่อนด้วยส่วนต่างดอกเบี้ย US–JP เป็นหลัก
   (US 2Y/10Y yield, JGB yield, DXY, ข่าว/ปฏิทินเศรษฐกิจ) → คัดกรองด้วย `feature_screen.py` ก่อนใส่ RL ทุกครั้ง
2. **ใช้สิ่งที่พยากรณ์ได้** — โมเดลคุมความเสี่ยงตามความผันผวน (vol targeting) แทนการเดาทิศ
3. **หยุดลงทุนกับ PPO บน feature ชุดนี้** — รวมถึงยังไม่รัน walk-forward 4 ชม. เพราะผลคาดได้ว่าไม่มี edge
